# Colony Care & Cleanup / 殖民地照护与清理优化

这是一个 Oxygen Not Included 复制人照护与清理便利合集。

包含：

- 伤员照护引导
- 智能食物消耗
- 可拾取掉落优化
- 小液滩清理增强
- 塌落材料自动补挖
- 腐烂食物自动清扫，v1.0.7 改为小批量分片扫描，减少大型基地周期性卡顿

说明：

- 本合集不新增建筑、不新增资源、不改配方。
- v1.0.7 优化腐烂食物后台扫描：每次只处理少量物品，并限制单次扫描耗时，优先保证大型基地游玩时更顺滑。
- v1.0.5 重新加入塌落材料自动补挖，并加入安全保护，避免已经消失或正在清理的地块导致崩溃。
- 启用本合集后，请关闭被整合的单独模组，避免重复加载。
